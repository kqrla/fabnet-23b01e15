# roadmap

## short term

- finish the authoritative resource audit for every supported city.
- verify and publish additional public fabrication locations in the external directory.
- send an administrator email when a maker requests approval.
- remove broad public read and update access from moderation submissions.

## mid term

- add private file storage for fabrication requests and maker portfolios.
- add secure requester and maker messaging.
- add an administrator review surface for locations, submissions, and maker approvals.
- improve postcode coverage and localized labels outside the united states.

## long term

- add privacy-preserving distance matching and map clustering at higher density.
- support trusted institutional maintainers for campus resource records.
- provide a documented export for public directory data.
